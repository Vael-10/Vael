# Vael - Pokemon Emerald Emulator

A custom-designed web-based Pokemon Emerald emulator with a modern, sleek UI built with EmulatorJS.

## Features

✨ **Modern UI Design**
- Custom gradient-based cyberpunk aesthetic
- Responsive design (Desktop, Tablet, Mobile)
- Smooth animations and transitions

🎮 **Full Emulation**
- Game Boy Advance (GBA) emulation
- Keyboard controls
- Gamepad/Controller support
- Save & Load functionality
- Volume control and audio settings

🎨 **Customization**
- Display scaling (1x - 4x)
- Filter options (Sharp or Smooth)
- Volume control
- Responsive sidebar controls
